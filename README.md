# CRT 2026 – Campus Recruitment Training

Day-wise coding practice and notes from my college's Campus Recruitment Training (CRT) program, covering core DSA and SQL topics, conducted May–June 2026.

## Structure
Each folder corresponds to one day of training:

| Day | Topic |
|---|---|
| Day 1 | Basics |
| Day 2 | Arrays, Searching & Sorting |
| Day 3 | Linked List |
| Day 4 | Stack & Queue |
| Day 5 | Tree |
| Day 6 | Graphs |
| Day 7 | HashMap |
| Day 8–13 | SQL (I–IV) |
| Day 10 | CRT Test-1 |
| Day 14–15 | Practice Questions |

## Purpose
This repo tracks consistent, structured practice across the core data structures and SQL topics most commonly tested in campus placements — built up day by day rather than crammed.
